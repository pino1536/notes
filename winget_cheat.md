# WinGet cheat sheet

### install
`winget install --exact --id [PACKAGE]`

`--silent` / `--interactive`

`--installer-type zip`

`--custom [COMMAND]`

`--scope machine`

### show
`winget show --id [PACKAGE]`

### search

`winget search [PACKAGE]`

### list
`winget list`

### upgrade
`winget upgrade [PACKAGE]` / `winget upgrade --all`
