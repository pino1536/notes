## Packages

#### Git
`winget install --id Git.MinGit --installer-type zip --scope machine`  

#### Node.js:
`winget install --id OpenJS.NodeJS --installer-type zip --scope machine`  
`npm install -g npm@latest`

## Location

Installs always in:

`%ProgramFiles%\WinGet\Packages`

And ads links for PATH in:

`%ProgramFiles%\WinGet\Links`
